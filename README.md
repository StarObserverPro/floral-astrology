# 花间 · Floral Astrology

一个独立的花朵测验页面。当前只做 MBTI 风格的四组偏好：12 道原创中文情境题，每组 3 题，回答逐步塑造同一朵水晶与金属之花。题目类型入口以后再套；东方材质、五行、星座、测字等暂不实现。

## 当前范围

- 画面以花为中心，只展示当前题目、两个选项与连续植物曲线；配色与晨曦／夜晚用小型图形控件选择。无教程、开发者说明、账号或付费流程。
- 花形由 76 个有界参数生成，四种轮廓作为同一形态空间的端点：五瓣浅盘、密层重瓣、长瓣杯形、四瓣平展。答案既改变主轮廓，也影响厚度、长宽比、层间收缩、卷边、缺刻、扭转和不对称；并非换四个固定模型。同一分数下，实际答案序列还提供可复现的尺寸变化。2∶1 的轻偏好也会扩大轮廓差距，不要求每一组都全选同一侧。新增装饰参数用独立随机序列，保留既有花形基因的取值。
- 褶皱是三维生成函数的一部分：边缘波纹的幅度、频率、相位、斜向与边缘集中程度，瓣面折脊的幅度、频率、方向、锐度，以及边缘卷曲均独立参数化。密瓣花采用较强折叠，厚杯形花保持较平静的表面；法线由变形后的曲面求导，金属瓣缘跟随同一曲面。固定容量的 64×24 细分网格解析这些变化，不在答题时替换模型。
- 从闭合花苞开始，前两题仅调整花苞；第 3 题展开约最终尺寸 1/3 的外冠，第 6 题增加内层／花托和首批悬浮结构，第 9 题显露花心花蕊，第 12 题补齐内冠与晶簇。单层花保留其单层轮廓，通过花托、花心和外围结构完成阶段变化。
- 花托、花茎、底部金属环、垂晶、花蕊和悬浮晶片全部使用同一组生成参数。数量、长度、宽度、厚度、分布、比例与运动速度都有范围；不存在固定不变的底座。金属环仍为 0–2 件，保留共同中心与异步姿态。形态包括光滑环、5–12 边切面、1–3 次半扭转的带、二／三叶根式曲面的三维投影，以及单根连续的 (2,3)／(2,5) 环结。半扭转的奇偶性改变带的连接方式，曲面叶数和环结绕数也参与生成；一次绕行多圈仍只计一件。均保留实体厚度，隐藏变体不重复计算每帧形变。
- 首次出现前预编译完整花形和所有金属变体，在隐藏目标上运行完整后处理，再等待 GPU 完成；就绪后才开始花苞淡入并开放拍照。问卷在预热期间可以继续回答，首次展开不再临时编译新材质。上下文恢复也重新预热。
- 花瓣尺寸独立于开瓣与结构阶段，第 3／6／9／12 题的尺寸目标约为 33%／60%／88%／100%，中间各题也继续增长。花苞独立淡入约 2.3 秒，重开时重新淡入；背景不跟着花苞一起淡出。
- 颜色由答案与种子生成。四种宝石色为基调，可用三种图形切换同色晶谱、邻色流光、对色幻彩。金属有独立的色相、色距、色度、混合比例与空间分布参数；同一部件可以呈现两种合金色与银色过渡，不再把所有金属统一染成金色。瓣缘、花托、花茎、花蕊和金属环共用生成色组并按部件错开分布，保留真实金属反射。配色渐变不随时间循环变色，色彩选择与照片输出使用同一套参数。
- 每次选择从当前形态指数趋近新目标，约 2 秒完成本次变化的 60%；动画不阻塞读题。固定容量的实例网格在 GPU 上形变，答题时不替换场景、渲染器或模型资源。
- 默认绕略微倾斜的轴缓转；鼠标拖拽、手机单指拖动均可旋转，释放后有轻微惯性，短暂停留后继续自动转动。轨道按钮或双击花朵恢复默认视角，键盘方向键也可调整。
- 拍照输出 1600×2000 PNG，保留当前角度、配色、生长阶段和光照，排除题目与按钮；完成后带四字母结果。先预览，再保存或调起系统文件分享；浏览器支持时也可复制图片。照片只在本机生成。
- 画质采用超采样 + HDR 格式实际支持的 MSAA + SMAA。普通 DPR=1 屏幕也以 1.6 倍绘制；最高 DPR 2.75，像素预算 650 万，持续慢帧时降到至少 1.25 倍。避免把只支持 4 样本的 GPU 错选为 0 样本。加粗实体金属边，适当拓宽高光，减少细线与闪烁。
- 花朵使用真实三维物理透射、色散、环境反射、面光源与点光源。按钮纹样由连续参数曲线生成，包括带高次谐波的植物轮廓、笛卡尔叶形的有限闭环，以及 3∶2、2∶3、4∶3 李沙育图形；随题目更换频率和相位，每个纹样保持一条闭合笔画，叶形保留其尖点，不绘制发散支。按钮随屏宽和指针类型微调尺寸，鼠标保持手形与悬停反馈。英文结果与照片字母保留哥特花体，下方另附小号普通字体供辨识。WebGL 不可用时显示明确的平面花形，也不绘制伪三维质感。
- 真实面光源与点光源按缓慢轨道运动，并共同驱动低分辨率的 24 步空气散射积分；背景配色单独控制，不把背景亮区当作灯。散射当前不含体积阴影。双向半分辨率弥散保留主体细节，文字与按钮不经过柔焦。静态照片复用同一光照与后处理。
- 当前答案只保留在本次页面内存中。刷新重新开始；返回可重答。字体随站点加载，不向外部问卷服务提交答案。
- WebGL 无法建立时切换到同样受答案驱动的纯平面 Canvas 花形，保留完整测验和晨夜选择。两种渲染路径共用评分、进度与参数含义。

12 题、约 1–2 分钟是本页的体验目标，尚未经过用户完成时间测量。本题库借四组偏好组织原创问题，不等同于正式 MBTI 量表。主流参照 [16Personalities 为 60 题](https://www.16personalities.com/free-personality-test?content_language=English)，[其官方指南称约 10 分钟](https://www.16personalities.com/articles/how-to-take-a-personality-test)。本页没有复制其题库或推定所有用户的耐心。

## 开发

```sh
npm ci
npm run dev
npm test
npm run build
```

静态产物为 `dist/`。Three.js 负责单一场景和帧循环；花瓣形变在 GPU 执行，题目切换不重建场景。环境、网格、材质与后处理资源由 `FlowerScene` 统一释放。`?qa` 暴露只读检查状态；配合 `specimen=ESTJ/INFP/ISTJ/ENFP` 和 `answered=0..12` 可重现真实评分的检查状态，不增加页面控件。

已通过 32 项自动检查，覆盖评分、四种轮廓跨度、参数边界、金属结构随种子变化、环同心、花苞与阶段、旋转、AA 采样选择、导出命名、参数曲线闭合、扭带接缝、环结实体法线、多色金属与真实花瓣褶皱。实际画面须同时核对闭合花苞、四种极端轮廓、完整答题、手机尺寸和 PNG 输出；手机视口模拟不等于手机 GPU 帧率实测。

## 来源

- 早期花形实现参考水晶花园的宽度轮廓与姿态参数思想：[plant-geometry-v31-runtime.ts](https://github.com/StarObserverPro/crystal-garden/blob/d60044a8bbe5682573bb518841baa3418d9d6efa/app/crystal-garden/scene/plant-geometry-v31-runtime.ts)。现已扩展为独立的连续轮廓、实体厚度与实例网格，不引入原项目的世界和游戏状态。
- 题目字体 [Ma Shan Zheng](https://github.com/googlefonts/mashanzheng)，选项字体 [LXGW WenKai TC](https://github.com/lxgw/LxgwWenKai)，结果字母 [UnifrakturMaguntia](https://github.com/google/fonts/tree/main/ofl/unifrakturmaguntia)，本地子集重命名为 Floral Gothic。字体均使用 OFL，随源代码附许可与本页字符子集。
- 曲面的分支思想参考 [NIST DLMF 复变函数](https://dlmf.nist.gov/1.10)；当前双叶金属带是环域上 `(z, sqrt(z))` 的三维艺术投影，不等同于完整黎曼面的嵌入。
- 连续纹样采用 [MIT 几何建模教材中的笛卡尔叶形参数表达](https://web.mit.edu/hyperbook/Patrikalakis-Maekawa-Cho/node5.html)与 [UMass 李沙育曲线讲义](https://people.umass.edu/~bvs/281_Lissajous.html)，在 SVG 内按解析导数转为连续 Bézier 段；无需位图装饰资产。
- [MBTI 四组偏好的含义](https://www.myersbriggs.org/my-mbti-personality-type/the-mbti-preferences/)。视觉对应为本项目的艺术设计。
